# 🧠 NeuroCare – Cognitive Training Android Application

NeuroCare is an Android-based cognitive training application designed to help users improve and practice their cognitive skills through interactive brain-training games.

## ✨ Features

- 🧩 **Memory Match** – Practice memory and recognition skills.
- 🎯 **Attention Training** – Improve focus and attention.
- ⚡ **Reaction Time** – Test response speed.
- 🔍 **Odd One Out** – Identify different objects through visual challenges.
- 📊 **Progress Tracking** – Monitor training activity and performance.
- 📜 **Session History** – Review previous training sessions.
- 🎨 **Theme Customization** – Personalize the application appearance.
- 📄 **PDF Export** – Export progress reports.

## 🛠️ Technologies Used

- Java
- XML
- Android Studio
- Android SDK
- SharedPreferences
- Git & GitHub

## 📱 Application Platform

- Platform: Android
- Development Environment: Android Studio
- Programming Language: Java
- UI Design: XML

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Anuradhamga/NeuroCare.git
   ```

2. Open the project using Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or start an emulator.
5. Run the application.

## 🎯 Project Objective

The main objective of NeuroCare is to provide an interactive platform for cognitive exercises and personal performance tracking through simple and engaging brain-training activities.
